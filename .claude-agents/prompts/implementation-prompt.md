# Implementation Prompt Template

Use this prompt template for code implementation tasks.

## Instructions

Implement the following feature/fix according to these requirements:

### Requirements

[Describe what needs to be implemented]

### Technical Context

- **Tech Stack:** [List technologies used]
- **Architecture:** [Brief architecture overview]
- **Existing Patterns:** [Patterns to follow]

### Implementation Guidelines

1. **Code Quality**
   - Follow existing code style and patterns
   - Write clean, readable code
   - Add appropriate error handling
   - Include TypeScript types where applicable

2. **Testing**
   - Write unit tests for new functionality
   - Add integration tests if needed
   - Test edge cases and error conditions

3. **Documentation**
   - Add code comments for complex logic
   - Update API documentation if needed
   - Document any breaking changes

### Expected Output

Provide:
1. **Files Created/Modified** - List of files with descriptions
2. **Code Changes** - Detailed code implementation
3. **Tests** - Test files and test coverage
4. **Documentation** - Any documentation updates
5. **Usage Example** - How to use the new feature

### Review Checklist

- [ ] Code follows project patterns
- [ ] Error handling implemented
- [ ] Tests added and passing
- [ ] Documentation updated
- [ ] No breaking changes (or documented)
- [ ] Performance considered
